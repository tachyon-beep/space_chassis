## Findings, ranked

1. **Low (design gap) — a legitimate genesis crash is journaled as a tampered root record.** Kill after row 1's fsync and before `_write_root_record` (T=0, L=1): the root record is `attach`'s unbound copy (`world_id: null, tick: 0`) and `classify_root_record` (tools/console.py:4286–4313) answers `rewrite` with a `root_record_rewritten` event, because B9/ADR (xxv) limit "routine" for an unbound record to T=L=0 and the `[T, L]` rule requires `world_id` to match. The event is documented to mean "damaged or tampered" (console.py:4290–4296). Scope: only the first boot's first cycle — after any resume the root is bound, and a pre-root-write kill at any later tick is routine (verified: e2e kill 1 left root at 60, windows at 59). Docs match the code, so this is a design choice to revisit, not a mismatch. Suggest: an unbound record at tick 0 is routine whenever T=0 (the genesis checkpoint precedes every row). Repro: `inproc.py::probe_root_at_tick_one`.
2. **Low (message ordering) — the S11 sentence is reachable only on a clean diode directory.** `main` checks the bound root record (console.py:5054–5061) and the legacy `pending.json` (5021–5052) before `state_record_files` (5063–5072). With the diode directory intact and the checkpoints gone from the state directory, the operator is first told "clear or rename the directory (ADR 0001 choice D)" — the diode directory — and only after doing that is told to move the journal. Both directories are stale in that state, so no single sentence is "right"; but the first points away from the directory that is the problem. Genesis is mandatory, so "record and no checkpoint" is reachable only by hand, hence low. Repro: `refusals.py` d3. The shipped test uses a fresh diode directory.
3. **Doc nit — ADR 0002 (xxvi)/README call `wall_down→wall_up` "the downtime gap".** `wall_up` is taken inside `_resume` (console.py:4522) after `load_world`, so the gap includes the vehicle's own startup: e2e restarted immediately after the kill and recorded 5.4 s. Already labelled a proxy; one clause would make it exact.
4. **Message nit** — a changed `--journal` refuses with "`other.jsonl`, which holds the checkpoint's anchor, cannot be opened (ENOENT)" (console.py:1821–1858 via 4411–4416) without naming the previous `--journal` path where the record lives.
