## 8. The full-suite failure (Emmy §12) — diagnosis and disposition

**Observed [code/log]:** `tests/test_vehicle_reconciliation.py::test_the_vehicle_passes_the_contract_probe`
failed at line 259 in the coordinator's full run (1722 passed, 1 failed; log

check got both results 0.5 ms apart (`20261010T091852_453533Z`, `…454054Z`), so the vehicle was
cycling normally; the following check (`an unknown verb is refused by name`) passed. The same test
passed in the coordinator's root-only run and in each of this session's root runs today (569 at
`3ec1b4e`, `486960c`, `1effa04`, among others).

**What was tested:** the test launches `docs/deep_research/vehicle/tools/console.py` from the
working tree at `--poll 0.05`. In the main checkout that tree is the vehicle line's `8c6f71d`, not
the pinned `dd79e76`, so this gate measures an unpinned, in-development vehicle **[code]**.

**Leading candidate cause — not established:** vehicle #39. At `8c6f71d`, `claim()`
(`tools/console.py:375-398`) reads `console.json` and then atomically writes an emptied copy over
it **[code]**. The probe's `submit()` (`contract/diode_probe.py:99-106`) replaces the file with
`os.replace`; one landing between the vehicle's read and its rewrite is overwritten, so the batch
never runs and no result is written — exactly the observed signature. Load from the full suite
(xdist plus the vehicle's own referee tests) widens that window, which fits pass-alone /
fail-under-load. The vehicle line independently names the same candidate (its AUR-GOV-07 §6).
Unexcluded alternatives: a vehicle stall longer than the probe's 15 s wait (unlikely given the
0.5 ms preceding results, but the fixture sends the console's stdout and stderr to `/dev/null`, so
no vehicle-side evidence exists), and a behaviour change in `8c6f71d`'s malformed-batch path
(unlikely, since the same tree passes otherwise).

**Disposition recommended (no waiver, no test change, no fix here):**
1. Classify it as an intermittent product defect candidate in the vehicle, tracked by vehicle #39

4. For publication: **John's decision** (see §9). Options: wait for #39 and its adoption; or a
   documented, scoped exception for documentation-only commits while #39 is open; or a second,
