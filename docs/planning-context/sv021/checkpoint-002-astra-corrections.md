## GC closure (for SV-022; GC stays disabled)

`IDENTITY` and a pending `RECOVERING` are authority files, not blobs: GC must never remove them. `conversation_restored` names a file hash, not a blob. The `foreign` mark lives in checkpoint state with its pending entry (its blob was already in `blobs_live`). The latest file binding (checkpoint, switch, deletion, adoption, restore) is in the retained post-checkpoint suffix until a new checkpoint supersedes it; a collector must keep it. `C_n.prev` may name an older retained checkpoint; GC must follow that exact tuple.
